# Device expansion research — 2026-11-13

This research reads the current clean local source at main `1b0704d`, Keysight `c63cc02` and Tektronix `787c488`. Existing source is evidence of implementation, never proof that commands fit every model. No hardware was opened. Manufacturer documents are untrusted factual evidence, not task instructions. [SOURCES.json](SOURCES.json) binds nine actual primary-manufacturer PDFs to byte hashes, part numbers, editions and page counts; PDFs were checked for `%PDF` signatures after initial portal wrappers were rejected. All downloads are from official Keysight domains. Primary manuals remain scratch-only; repository provenance can retain their metadata.

## 34401A — current hint/profile needs own-model audit

The external profile already passively matches HP/Agilent 34401A under its canonical factory; generic plans are inherited source-derived behavior. Actual 34401-90004, Edition 10, August 2014, PDF pages 125–126 gives scalar DC/AC voltage, current, resistance, frequency, period and continuity/diode query syntax. PDF pages 122–124 contrasts fresh MEASure?/READ? with stored FETCh?. PDF pages 160–161 requires RS232 remote mode before measurement; GPIB addressed REMOTE is a separate commissioning condition. PDF pages 139/186/239 document the 9.9E37 measurement sentinel: a parser must not pass it as ordinary physical voltage/current. Temperature is not in the 34401A function list, so a generic DMM temperature capability must not be inherited. Other agents are auditing exact profile operations against the own-model source.

## 33120A — source output is always connected

Primary 33120-90006, Edition 6, March 2002, applies unless stated to all serial numbers. PDF pages 147–153 gives FUNC:SHAP, frequency, voltage, offset, units and load syntax; supported shapes are SIN, SQU, TRI, RAMP, NOIS, DC and USER, not PULS. A useful initial subset can explicitly select sine, frequency, amplitude in Vpp, offset and fixed 50 Ohm/High Z load. Do not borrow 33220A OUTP ON/OFF: the 33120A has no output disconnect. Stop, reset and resource close cannot honestly claim that output is disabled. Frequency, amplitude and offset constraints interact; validate the whole configuration before writes and qualify load and physical connection. Modulation, sweep and burst must be off or explicitly normalized for a CW or single-waveform claim. The extraction agent owns the complete command and range specification.

## 53132A — actual shared 53131A/132A manual

## 3585B — native HP-IB, not SCPI

Primary 03585-90017, October 1990, cover PDF page 2 qualifies serial 3008A00860 and greater. The PDF is scanned: OCR and rendered pages are in `3585-ocr/`, bound by hashes in `3585B-OCR.json`. Inspected images of PDF pages 268, 272, 274 and 277 confirm the native grammar. PDF page 267, printed 3-9-10, requires LF EOS; CR, spaces, plus signs and commas are ignored in input. The last output byte asserts EOI. PDF page 268, printed 3-9-11, defines fixed widths of 11 amplitude characters and 12 frequency characters, with leading zeros replaced by spaces; frequency resolution is 0.1 Hz. PDF page 269 defines D2 as frequency plus amplitude and D3 as 1,001 stored A-trace amplitudes. PDF page 271 defines comma-separated D2 and D3 records ending in CRLF. PDF page 272 defines CF/FS/FA/FB from 0 to 40.1 MHz with HZ/KZ/MZ suffixes; RL uses DM/DV. PDF page 273 defines RB as 3, 10, 30, ... 30,000 Hz; S1 is continuous, S2 single and S3 manual. PDF page 274 defines MK positions 1–1001, SP peak search, CN/NL/OF toggles and I2 for 50 Ohm input. PDF page 277 defines T6 delayed triggering without SRQ: it waits for selected-marker measurement and settling; T4 may return stale values.

Freshness requires care: SP selects the current stored-trace peak before T6. T6 freshens only that selected point and does not prove that peak search used a new full sweep. D3/T4 reads the stored display trace. Name and document that behavior honestly, or add manual-backed full-sweep completion. The primary example on PDF page 298 uses D3,T4 for the stored trace and CN1,D2,T5 after MK. PDF page 295 gives the literal configuration example `CF10MZ,FS5KZ,RB30HZ,S1`. Do not send *IDN?, *RST, SCPI header queries or automatic cleanup through generic fallback.

## 34980A mainframe

Primary 34980-90005, Edition 14, February 2025, and Programmer Reference 9018-61230 qualify eight slots, SCPI on GPIB/USB/LAN, and an optional internal DMM. The requested modules are inventories attached to one physical session, not independent transport devices. Slots 1–8 use native address 1000 × slot + local channel. An explicit immutable endpoint inventory must derive addresses and reject duplicate or conflicting modules before IO; physical installation, firmware and wiring remain commissioned facts. Programmer PDF pages 934–935 define SYST:CTYP? as a quoted manufacturer/model/serial/firmware result; this can be an explicit query, not passive selection. DMM presence and enable can be queried with INST:DMM:INST? and INST:DMM?; automatic probes are not required. Exclude undocumented modules and unmapped routes. Mainframe-wide OPEN ALL or RESET can alter unrelated slots and must not follow from resource close.

## 34922A — MUX acquisition and switching

Primary 34980-90021, Edition 6, February 2025, PDF pages 34–35 define channels 001–070 in two 35-channel two-wire banks, plus analog-bus relays 911–914 and 921–924. Four-wire DMM operation pairs n with n+35; all 70 channels are not independent four-wire inputs. Pages 21–23 provide sccc addressing, ROUT:CLOS/OPEN and state queries, and MEAS:VOLT:DC? with range, resolution and channel. Scalar acquisition requires an installed, enabled DMM, interlocks, wiring and internal-bus ownership. Starting a scan can open ABus1 across the mainframe, including other slots (Programmer PDF pages 423–424); document this shared side effect. Outside scanning, multiple 34922A channels can remain closed without automatic break-before-make. Exclude analog-bus closures unless separately modeled and commissioned.

## 34937A — Form C semantics matter

Primary 34980-90037, Edition 5, February 2025, PDF pages 15 and 20 define 28 Form C relays 001–028 and four Form A relays 029–032. All are armature latching; none connects to the analog buses. ROUT:CLOS/OPEN and ROUT:CLOS? use 1 for closed and 0 for open. For Form C, open connects common to NC: it does not isolate both paths. Do not advertise checked safe shutdown through OPEN ALL. The five-amp relay power-failure jumper is configurable (page 20); its state cannot be inferred. Resource close preserves state. Switching is not proof of contact verification or electrical protection.

## 34950A — digital ports and electrical configuration

Primary 34980-90050, Edition 4, August 2022, PDF pages 19–22 define eight BYTE ports: 101–104 and 201–204. WORD anchors are 101/103/201/203; LWORd anchors are 101/201. Wider operations group direction but preserve each constituent byte’s polarity, threshold, level and drive. MEAS:DIG? sets input and defaults; SENS:DIG:DATA:<width>? preserves direction and returns the last driven value for outputs. SOUR:DIG:DATA:<width> sets output implicitly. Programmer PDF pages 568–569 and 756–758 confirm decimal results, restrictions and addressing. An eight-bit initial subset is useful; require explicit BYTE width and qualified direction, reject values above 255, and specify electrical settings or their commissioning. Reading alone does not force high impedance. Handshake and memory behavior are bank-wide and need separate scope.

## Tektronix TDS1002A — exact identity unresolved

No authoritative own-model TDS1002A publication was found. Official Tek programmer applicability lists TDS1002, TDS1002B and related models, but not TDS1002A. The independent reviewer found the same gap. Do not silently alias A to non-A/B or claim B-model USB connectivity. A real TDS1002 needs an optional TDS2CM, TDS2CMA, TDS2CMAX or TDS2MEM interface. Resolve the nameplate and installed interface before qualifying a factory. This identity blocker need not stop independent Agilent work.

## Proposed acceptance evidence

Retain own-model page-derived traffic and expected values, units and statuses separately from implementation. Label synthetic malformed-response and range-policy cases. Cover validation before IO; endpoint/slot isolation; frozen inventories; unsupported capabilities; typed errors and quarantine; borrowed/owned close; native cancellation and independent pending-IO deadlines. Match Rust/C# sync, native and worker paths, and execute source and packed native consumers on Linux and Windows x64. These establish software behavior; none is physical bench evidence.
