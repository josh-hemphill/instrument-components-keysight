## Neutral API and package boundary

No family alias, wildcard inference, automatic `*IDN?`, option query, reset or output enable at matching/open. Cross-model names in copied manual examples are excluded from model evidence. All HP commands, parser, options and topology remain in independently distributed external Keysight code; core must not depend on or bundle it.

Required operations are `RfSignalGeneratorConfigure(frequency_hz,level_dbm)->Unit`, `RfSignalGeneratorOutputEnable(enabled)->Unit`, `RfSignalGeneratorOutputStateQuery()->Boolean`, `RfReceiverMeasureFrequency()->Quantity(Hertz)`, and `RfReceiverMeasurePower()->Quantity(Dbm)` only on RFInOut receiver input. Configure disables output and leaves it disabled; it confirms digital settings, not physical settling/calibration or unmodulated CW. Preserve modulation settings. ## Exact common normalization prefix

Validate the complete request and immutable selected route before IO, then serialize the whole transaction under one runtime lease. Use grouped CONFIG writes and grouped readbacks consistently in both languages. Manual permits interleaving setting/readback pairs; this grouping is deterministic software transcript policy, not an exclusive manual ordering. Hard requirement: verify output OFF before CONFIG writes and verify all CONFIG fields before proceeding.

1. write`DISP RFG`;write`RFG:AMPL:STAT OFF`;query`RFG:AMPL:STAT?`→bare0.
2. write`DISP CONF`;write`CONF:ARTS 'Manual'`;write`CONF:OMOD 'Off'`;write`CONF:OFL:MODE 'Off'`.
3. query`CONF:ARTS?`→quoted Manual;query`CONF:OMOD?`→quoted Off;query`CONF:OFL:MODE?`→quoted Off.

Fail immediately without retry, later cleanup commands or ignored verification. CONFIG owns manual switching,frequency-offset linkage and all software RF level offsets, making values port referenced with no hidden cable/attenuator correction.

## Source configure continuation and output state

Before any IO require finite frequency within selected model bounds at integer1Hz resolution and finite level within selected port/option bounds at0.1dB resolution. Otherwise InvalidArgument, no clamping/rounding/port substitution.

After prefix:

1. write`DISP RFG`;write`RFG:AMPL:STAT OFF`;query`RFG:AMPL:STAT?`→0 again.
2. write`RFG:ATT 'Off'`;query`RFG:ATT?`→quoted Off.
3. write`RFG:OUTP 'RF Out'`or`RFG:OUTP 'Dupl'`from immutable route.
4. write`RFG:FREQ <frequency_hz> HZ`;write`RFG:AMPL <level_dbm> DBM`. Format frequency as fixed integer Hz and level as canonical invariant decimal tenths (e.g.30000000,-30,-20.5,0).
5. write`RFG:AMPL:UNIT DBM`;query`RFG:AMPL:UNIT?`→DBM.
6. write`RFG:AMPL:STAT OFF`;query`RFG:AMPL:STAT?`→0.
7. query`RFG:OUTP?`;query`RFG:FREQ?`;query`RFG:AMPL?`;require route port and requested setting within0.5Hz/0.05dB digital tolerances.

Only then set configured=true. DUN display units cannot replace UNIT. Numeric GPIB writes preserve an OFF field; front-panel numeric entry differs. Confirming settings does not establish RF settling. Do not add`*OPC?`, which can wait for unrelated active measurements.

Enable/disable first write`DISP RFG`;write`RFG:AMPL:STAT ON`or`OFF`;query`RFG:AMPL:STAT?`requiring1or0. Enable(true) requires configured=true before IO;disable is available before configuration. State query writes`DISP RFG`then queries`RFG:AMPL:STAT?`,returning0/1 Boolean without a state write or inferring readiness.

## Fresh receiver continuation

Validate request before IO and clear source configured state before receiver IO. Apply the common prefix once,write`DISP RFG`,write`RFG:AMPL:STAT OFF`,query`RFG:AMPL:STAT?`→0,then write`DISP RFAN`.

1. write`RFAN:INP 'RF In'`or`'Ant'`;write`RFAN:TMOD 'Auto'`;query`RFAN:INP?`then`RFAN:TMOD?`;require route input/Auto.
2. For power reject ANT before IO;write`MEAS:RFR:POW:UNIT DBM`;query same`?`→DBM. Frequency uses fixedHz.
3. Let P=`MEAS:RFR:FREQ:ABS`or`MEAS:RFR:POW`. Write`P:AVER:STAT OFF`and`P:REF:STAT OFF`;query both state settings→0.
4. write`P:STAT ON`;query`P:STAT?`→1.
5. write`TRIG:MODE:SETT FULL`;write`TRIG:MODE:RETR SING`;query each→bare FULL/SING.
6. write`TRIG:IMM`;query`P?`;parse one fresh finite quantity inHz/Dbm within model receiver envelope.

Repeat full transaction and trigger on every call. Consecutive query alone in SING can return old data. Display activation,measurement ON,averaging/reference OFF,FULL and SING are operation steps,not implicit commissioning. Caller supplies a suitable stable single carrier. Power-only does not query frequency; applicable carrier band is commissioning precondition. After receiver success,enable requires fresh successful source configure. No reset,busclear,abort,retry,old result or`*OPC?`substitution.
