## Public boundary and immutable inventory

Only `DataAcquisitionMeasureVoltageDc(channel, range?) -> Quantity(Volt)` is required. Channel is a positive public physical identifier; range is volts. Canonical factory `keysight.hp3497a`, endpoint scheme `hpib`, exact application identity manufacturer `HP` or `Hewlett-Packard`, model `3497A`. Explicit factory selection still checks scheme. No matching/open ID query, SCPI fallback, probing, reset or output enable. Manufacturer commands, parser and topology remain exclusively in the external Keysight package; core must not depend on or bundle it.

Require Option001 DVM explicitly present, confirmed normal DVM routing and at least one supported input. Every mapping declares positive public ID, mainframe slot0–4, local0–19, native address0–99, module type and compensation. Require `native=20*slot+local`; this validates supplied inventory without discovering wiring. Option010 accepts local0–19 with None compensation. Option020 accepts only commissioned Software compensation and user channels0–18; local19/B9 is the software reference junction and is not a user input. Hardware compensation adds voltage, so Hardware/Unknown compensation is invalid for raw voltage. Normal routing means JM1–JM3 normal DVM route and JM4–JM6 standard decade connections are intact and compensation wiring matches inventory.

Reject before connector open: missing DVM, unconfirmed routing, empty/unknown inventory, duplicate public IDs/native addresses, inconsistent slot/local/native, conflicting module/compensation declarations in a slot, unsupported module or compensation, reference channel. SR code7 is analog OR empty and cannot prove inventory. Do not advertise070/071, extenders, rear-terminal direct DVM, scans, temperature conversion, digital/counter/actuator/DAC/breadboard outputs. Their output state is unknown. Scalar DMM and pair-terminal Switch operations do not represent this topology. Identity, Reset and global Shutdown are omitted.

## Immutable endpoint routing

Register one canonical factory with an explicit immutable map of endpoint bindings. Each binding owns that exact endpoint's Option001 presence, normal routing and commissioning confirmations, module inventory and channel map. Normalize endpoint scheme with ASCII case-insensitive rules; compare address exactly. Deep-copy and freeze all supplied records/maps at factory construction, reject duplicate endpoints and invalid selected inventory before connector open, and never retain mutable caller data as authority.

There is no fallback chassis inventory or default binding for arbitrary addresses. An unbound endpoint rejects before connector open. Capabilities and required operations are validated against the exact selected route before obtaining IO; one chassis's supported channel map cannot authorize another endpoint. Matching and opening do not probe identity/modules or reset anything. Sync, worker and native paths use the same selected frozen route and advertise only connector paths actually supplied.

## Exact acquisition

Validate full request before IO. Supported exact explicit ranges0.1,1,10,100 V map to VR1,VR2,VR3,VR4; null maps VR5 autorange. Other values raise InvalidArgument without IO; no rounding or nearest selection. Unknown/nonpositive public channel raises InvalidArgument.

Under one runtime lease issue `query` with exactly this uppercase native body and no appended question mark, separator, or SCPI punctuation:

`VT4AE0VC0VS0VF1VN1VW0SO1VRnAIc`

Here n is the range digit and c the mapped native decimal address. VT4 holds acquisition;AE0 disables external increments;VC0 disables inherited DVM current source;VS0 disables storage;VF1 selects ASCII;VN1 selects one result;VW0 removes inherited wait;SO1 paces controller reads;AIc closes requested input and triggers measurement. Never issue bus GET because it advances channels. It changes closure/DVM settings and need not preserve a prior scan.

Connector commissioning must establish native GPIB operation, an initially clean complete-response boundary, exclusive device access and no concurrent external trigger/controller/scan changes before returning IO. A fully framed stale response is not automatically detectable. A connector unable to guarantee the boundary must reject open. AE0 is explicit but does not establish an entire uncontrolled session's history.

## Parsing

Host supplies one bounded complete ASCII body without framing CRLF. Accept exactly11 bytes `[+-][0-9]\.[0-9]{5}E[+-][0-9]`, no whitespace, and finite scalar numeric result. The diagram's graphical spacing is not a literal space. Reject comma/list/multiple readings, time/channel output, binary, embedded controls, non-ASCII, missing data, NaN/Infinity, trailing junk and oversized bodies as Parse. Complete scalar host response bound256 bytes is software policy and must be checked before allocation.

Recognize exactly `+9.00000E+9` as `Quantity(0,Volt,Overload)`; zero is only a status placeholder. Negative `-9.00000E+9` is not the documented sentinel. After sentinel recognition reject absolute values greater than120 V as Parse;120 V peak maximum is documented. Inclusive ±120 V are valid. This filter does not prove freshness or physical protection.

## Failures and ownership

Typed Timeout/Transport retain their classifications. Partial IO, failed selection, malformed response, timeout or active cancellation quarantines the session; later operations raise SessionNeedsRecovery before IO. Queued cancellation/pre-IO InvalidArgument/UnsupportedOperation do not quarantine. No automatic retry, device clear, reset, extra read or compensating command after failure. Recovery is unsupported; application-controlled bus/device recovery and reopening/recommissioning are required. Draining or unchanged output buffers cannot prove synchronization.

Owned IO closes exactly once, borrowed IO stays open, failed open releases acquired owned resources. Close is resource-only and does not claim all unknown chassis outputs disabled. Native async uses actual async IO/cancellation, not synchronous IO wrapped in async. Rust/C# share argument validation, units, statuses, errors and sync/worker/native behavior; static registration supports .NET Native AOT.
